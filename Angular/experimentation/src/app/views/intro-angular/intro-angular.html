Introducción a Angular

Angular es un framework de desarrollo en entorno cliente creado por Google para construir Single-Page Applications (SPA) usando HTML y TypeScript, basado en componentes web reutilizables.

1. Angular CLI (ng)

Utilidad de consola para automatizar tareas repetitivas como crear proyectos, generar componentes o lanzar el servidor.

2. Estructura clave de src/ (Interactivo)

Haz click en un archivo para ver su función dentro de Angular:

@for (file of projectFiles; track file.name) { }
{{ selectedFile }}: {{ selectedDescription }}

3. Anatomía de un Componente

Al ejecutar ng generate component components/header se crean 4 archivos: .ts (lógica), .html (vista), .css (estilos) y .spec.ts (tests). Para usarlo en otro HTML se instancia mediante su selector: <app-header></app-header>.
