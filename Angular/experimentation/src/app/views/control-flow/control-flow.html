Control Flow: Bucles y Condicionales

Novedad desde Angular 17: sustituye a *ngIf, *ngSwitch y *ngFor con bloques nativos @if, @switch y @for directamente en el HTML.

1. Condicional @if / @else

@if (test) { Hello World! (test = true) } @else { Goodbye World! (test = false) }

2. Selector @switch

@switch (selectedCase) { @case ('one') { Resultado: Caso uno } @case ('two') { Resultado: Caso dos } @default { Resultado: Caso por defecto } }

3. Bucle @for, variables implícitas y @empty

El parámetro track es obligatorio para que Angular localice cada elemento tras reordenamientos.

@for (student of students; track student; let i = $index; let first = $first; let last = $last; let even = $even; let odd = $odd) {
#{{ i }} {{ student }} first: {{ first }} | last: {{ last }} | even: {{ even }} | odd: {{ odd }}
} @empty {
Array vacío (bloque @empty activado)
}
