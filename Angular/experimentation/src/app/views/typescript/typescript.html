Introducción a TypeScript

TypeScript es JavaScript mejorado con tipado estático. Tipos básicos: boolean, number, string, null, undefined.

1. Variables y Tipos

Si declaramos una variable con valor inicial, TypeScript infiere su tipo y no permite cambiarlo después (salvo que sea any).

2. Funciones: tipado, opcionales (?) y valores por defecto

Prueba en vivo (función con parámetro opcional/por defecto):

{{ greet(userName) }}
