Free Dictionary API - Sinónimos

Implementa la lógica necesaria para que se pueda introducir un término de búsqueda -una palabra en inglés-. Cuando el usuario pulse sobre el botón 'Buscar', se realizará una petición GET a la API Pública siguiente: Free Dictionary API.
A partir de los datos obtenidos de las respuestas de las peticiones GET, se deberá implementar un carrusel que permita visualizar los sinónimos de la palabra buscada. Mediante los botones anterior y siguiente de cada palabra, el carrusel deberá permitir pasar del primer sinónimo al último y viceversa.
Si el usuario realiza la búsqueda de otras palabras, se irán acumulando de modo que se puedan visualizar todas las palabras consultadas.
